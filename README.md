# EstateHub — вебсайт агентства нерухомості

EstateHub — це демонстраційний вебсайт агентства нерухомості з інтерактивним каталогом об’єктів. Проєкт створено для дипломної роботи за темою **«Розробка вебсайту агентства нерухомості з інтерактивним каталогом об’єктів»**.

## Реалізовано

- головна сторінка з пошуковим блоком;
- інтерактивний каталог нерухомості;
- фільтри за типом об’єкта, операцією, ціною, кількістю кімнат і пошуковим запитом;
- сортування об’єктів;
- детальна сторінка об’єкта з фотогалереєю;
- форма заявки на консультацію;
- сторінка контактів;
- сторінка «Про агентство»;
- адміністративна сторінка для додавання, редагування і видалення об’єктів;
- мінімальний backend на Node.js + Express;
- fallback-режим для GitHub Pages через `localStorage`.

## Як відкрити у VS Code

1. Завантажте та розпакуйте архів.
2. Відкрийте папку `real-estate-agency-site` у VS Code.
3. Для простого перегляду встановіть розширення **Live Server**.
4. Натисніть правою кнопкою на `index.html` → **Open with Live Server**.

Сайт працюватиме навіть без backend, бо у статичному режимі використовує файл `data/properties.json` і `localStorage` браузера.

## Як запустити мінімальний backend

Backend потрібен для демонстрації серверної частини: отримання об’єктів, додавання/редагування/видалення об’єктів і збереження заявок.

Потрібно мати встановлений Node.js.

У терміналі VS Code виконайте:

```bash
cd backend
npm install
npm start
```

Після запуску backend буде доступний за адресою:

```text
http://localhost:3000
```

Перевірка роботи:

```text
http://localhost:3000/api/health
```

Frontend автоматично спробує підключитися до `http://localhost:3000/api`. Якщо backend не запущений, сайт працюватиме у статичному режимі.

## Вхід в адмінпанель

Сторінка:

```text
admin.html
```

Демонстраційний пароль:

```text
admin123
```

У режимі GitHub Pages зміни з адмінпанелі зберігаються тільки у браузері через `localStorage`. 

## GitHub Pages

GitHub Pages не запускає Node.js backend, тому на ньому працюватиме статична частина сайту:

- головна сторінка;
- каталог;
- фільтри;
- сторінки об’єктів;
- форми;
- адмінпанель із локальним збереженням у браузері.


## Важливо про backend і GitHub Pages

GitHub Pages підтримує тільки статичні сайти. Тому повноцінний backend на GitHub Pages не працює. У цьому проєкті зроблено два режими:

1. **Локальний режим із backend** — запускається через Node.js і зберігає дані у `backend/db.json`.
2. **Статичний режим для GitHub Pages** — працює без сервера, а зміни зберігає у `localStorage` конкретного браузера.
